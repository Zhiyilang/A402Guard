# A402Guard

**一个可以提议、但永不决定付款的 A402 智能体。**

能花钱的智能体是智能体工程里最锋利的攻击面：账单文本、资源描述、跳转链条
全都由**卖方**书写，而**买方**才是掏钱包的那一个。冲着付费智能体来的提示注入
不是内容问题，是钱的问题。

A402Guard 实现了 A402（`HTTP 402 Payment Required`）买方闭环，并在钱的前面
放了一道**确定性花费防火墙**。

```
GET 资源  ──►  402 + Payment-Needed
                   │
                   ├─ 解码 + 结构闸门              (bill.py)
                   ├─ 校验卖方签名                  (bill.py)
                   ├─ 花费防火墙                    (guard.py)   ← 这里没有模型
                   │     ├─ deny        → 出收据，不扣款
                   │     ├─ needs_human → 挂起，不扣款
                   │     └─ allow       → 扣款
                   ├─ 幂等闸门（在扣款之前）        (ledger.py)
                   ├─ 付款 → Payment-Proof
                   └─ 带凭证重试 GET → 资源 + 收据
```

## 运行

```bash
python eval.py     # 89 条断言，离线，仅依赖标准库
python demo.py     # 对内置 mock 卖方跑端到端
```

两者都不需要联网、不需要 API Key、不需要任何第三方包。

## 强制保证的性质

| 性质 | 位置 | 怎么证明的 |
|---|---|---|
| **账单结构** | `bill.py` | 缺字段 / 金额非法 / 币种非法 / 日期非法，一律在其他任何逻辑之前抛错 |
| **卖方真实性** | `bill.py` | 对规范化账单做 HMAC-SHA256；篡改金额即验签失败 |
| **注入不能花钱** | `guard.py` | 21 条确定性规则，覆盖注入 / 越狱 / 伪造系统标签 / 工具劫持 / 外发 / 凭据 / 收款方替换 |
| **硬红线绝不降级** | `guard.py` | 外发、工具劫持、凭据、伪造系统标签——即使在明确的教育语境里也保持 `deny` |
| **误报代价可控** | `guard.py` | PII 使用**真校验位**（18 位身份证按 GB 11643、卡号按 Luhn）——一串随机 18 位数字不是身份证 |
| **预算是算术** | `ledger.py` | 全程整数分；超预算账单由减法拒绝，不由策略拒绝 |
| **只付一次** | `agent.py` | 重复检查在**扣款之前**执行；重放的账单被抑制，永不扣款 |
| **陌生收款方** | `agent.py` | 转 `needs_human`，不花一分钱，且留在收据里 |
| **每个决定都有收据** | `ledger.py` | 已付 / 拒绝 / 挂起 / 已抑制，各自带决定它的规则 id |

## 设计契约

* **仅标准库** —— 零依赖，Python 能跑的地方它就能跑
* **花钱路径上没有模型** —— LLM 可以提议去取哪个资源，但**永不决定**某张账单能不能付
* **确定性** —— 同一张账单永远得到同一个决定
* **钱是整数分** —— 浮点从不接触预算

## 与官方 A402 规范的差异

官方卖方签名是 **RSA2**。Python 标准库没有 RSA，因此 `bill.sign_bill` /
`bill.verify_bill` 使用 HMAC-SHA256 作为**调用形状完全一致的占位实现**。
换成 RSA2（用官方支付宝 SDK）只是替换一个函数，不触及 agent、guard、ledger
任何一个。其余部分——`Payment-Needed` / `Payment-Proof` 头部形状、账单字段、
402 → 付款 → 重试的闭环——均遵循已公布的协议文档。

## 目录

```
a402guard/bill.py     A402 编解码：Base64URL 账单、Base64 凭证、签名
a402guard/guard.py    确定性花费防火墙（21 条规则 + PII 校验位）
a402guard/ledger.py   幂等、有预算、有收据的花费账本（整数分）
a402guard/agent.py    买方闭环
mock_seller.py        离线 A402 卖方，每条对抗路径一个路由
eval.py               89 条断言（含真跑一次 LC_ALL=C 子进程）
demo.py               可打印的端到端运行
```
